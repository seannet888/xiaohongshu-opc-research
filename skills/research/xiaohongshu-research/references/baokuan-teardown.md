# 小红书爆款拆解框架（深度内容分析）

拆解「选题 / 文字结构 / 图片结构 / 钩子」时用，前提是已抓取笔记详情。

## 前置：数据从哪来

- `search-feeds` 只返回 `title` / `cover` / `interactInfo`（含 sharedCount）/ `type` / `user`，**不含正文**。
- 拆文字结构 / 图片结构必须 `get-feed-detail`，拿到 `note.desc`（正文）、`note.body`、`note.tags`、`note.imageList`、`comments`。
- 风控红线：详情抓取**最多 3 篇**（连续 4~5 篇必触发验证码），每篇 sleep 20s。

## 拆解六维度

1. 选题 —— 为什么选这个方向（人群 / 痛点 / 时效 / 差异化）
2. 文字结构 —— 标题公式 + 正文编排
3. 图片结构 —— 封面 vs 多图、每张图的角色
4. 钩子 —— 靠什么吸引点击 / 互动 / 转化
5. 转化路径 —— 流量往哪走（私域 / 主页 / 课程）
6. 数据信号 —— 用互动数据反推内容类型

## 选题公式（三类验证有效）

1. 搞钱工具型：人群 + 时效 + 工具 + 结果（普通人 + 国庆 + AI + 赚米）
2. 生活方式 / 招募型：身份 + 情绪反差 + 主题（一人公司 + 乡村 + 治愈）
3. 变现方法论型：动词 + 方法 + 结果（卖虚拟产品 + 互联网思维 + 超级个体）

## 标题 / 钩子公式（五种）

- 利益前置：直接说「赚米 / 变现 / 卖 XX」
- 人群锚定：普通人 / 一人公司 / 超级个体，让目标对号入座
- 时效紧迫：趁国庆 / 最新 / 全网首发
- 认知差：互联网思维 / 商业模式 / 用 AI
- 情绪共鸣：孤独 / 治愈 / 反内卷 / 不上班

## 文字结构模板

- **视频型**：钩子标题 + 一句预期管理 desc + 密集标签（抢搜索）+ 评论区运营（置顶导流 + 引导留言）
- **图文 / 招募型**：痛点反问 → 解决方案 → 反常识主张 → 用户画像（对号入座）→ 利益清单 → 金句升华 → 低门槛 CTA（评论 666）

## 数据信号解读（藏 / 赞比是钥匙）

- 藏 ≥ 赞 → 工具型（教程 / 方法论 / 清单），用户「收藏 = 想照做」
- 赞 ≫ 藏 → 情绪共鸣型（价值观 / 生活方式），「点赞 = 共鸣」但不可复制
- 转高 → 有传播价值（干货 / 争议 / 强情绪）
- 评「666」等机械词 → CTA 生效但互动质量低（招募类特征）

## 实例速记（2026-09-26 一人公司 / OPC）

- 国庆 AI 赚米（视频，124赞 / 116藏 / 17转）：工具型，标题四连钩子（普通人+国庆+AI+赚米），评论区置顶导流小号 @财女实验室
- 乡村疗愈 OPC（图文 14 图，91赞 / 3藏）：招募软文七段式，评「666」CTA，赞≫藏 = 情绪型
- 梁策卖虚拟产品（视频，82赞 / 117藏）：方法论型，desc 纯标签、内容靠视频口播，藏>赞
